# Andreea Tech Content Studio

Echipă de agenți AI pentru conținutul Andreea Tech, rulată direct în Claude Code. Fără aplicație, fără infrastructură.

## Structură
- `brand/brand-brief.md` — sursa de adevăr a brandului (citită de toți agenții)
- `.claude/agents/` — agenții

## Echipa
| # | Agent | Stare |
|---|---|---|
| 1 | `brand-strategist` | gata |
| 2 | `linkedin-content` | următorul |
| 3 | `social-media` | planificat |
| 4 | `content-research` | planificat |
| 5 | `content-editor` | planificat |

## Folosire
Ex.: „Folosește brand-strategist ca să completeze brand-brief.md" sau `@brand-strategist` în Claude Code.

# Andreea Tech Content Studio

Echipă de agenți AI pentru conținutul Andreea Tech, rulată direct în Claude Code. Fără aplicație, fără infrastructură.

## Structură
- `brand/brand-brief.md` — sursa de adevăr a brandului (citită de toți agenții)
- `.claude/agents/` — definițiile agenților
- `agents/` — fișa fiecărui agent

## Echipa
| # | Agent | Stare |
|---|---|---|
| 1 | `content-strategist` | gata |
| 2 | `linkedin-content-creator` | gata |
| 3 | `instagram-content-creator` | gata |
| 4 | `visual-content-creator` | gata |
| 5 | `content-researcher` | gata |
| 6 | `content-editor` | gata |

## Folosire
Ex.: „Folosește content-strategist ca să completeze brand-brief.md" sau `@content-strategist` în Claude Code.
